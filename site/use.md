# Use

There is no runnable SEO command or skill in 0.0.1.

The project currently provides the foundation that future capabilities will
use: a native plugin manifest and a typed evidence result. It does not yet
perform a site audit, fetch a public page, inspect HTML, query an SEO provider,
or generate a report.

When a skill ships, this page will provide a real request-and-result workflow
that can be reproduced from a Codex session.
