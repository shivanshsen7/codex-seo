# Install

There is no end-user installation path in 0.0.1.

The repository does not currently publish an installer, an NPM package, a
binary, or a release asset. Development dependencies support repository
validation; they do not make an SEO skill available to end users.

Watch the [Codex SEO repository](https://github.com/shivanshsen7/codex-seo)
for the first release that includes an installation path and at least one
usable skill.
