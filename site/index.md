# Codex SEO

Codex SEO is a native Codex plugin for evidence-backed SEO workflows. It is
being built so future SEO capabilities can return structured evidence rather
than unsupported conclusions.

## Current availability

Version `0.0.1` is the plugin foundation. It includes the native plugin
manifest, a TypeScript evidence-envelope contract, and development quality
checks.

No end-user SEO skills, commands, installers, published packages, or binaries
have shipped in this version. Read the Skills, Install, and Use pages for the
current availability of each part of the plugin.

## What this site documents

This documentation site describes what is actually present in the repository
today. It will add practical installation and workflow guides when a usable
skill ships.
